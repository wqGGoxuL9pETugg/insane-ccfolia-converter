# ココフォリアコンバーター / インセイン

インセインのキャラクター情報から、ココフォリアへ貼り付ける駒JSONを作成する非公式ツールです。

## 使い方

1. Web版を開くか、`index.html` をダウンロードしてブラウザーで開きます。
2. キャラクターシート倉庫のURLを読み込むか、フォームに手入力します。
3. 特技・生命力・正気度・持ち物などを確認します。
4. 「駒JSONをコピー」を押し、ココフォリアの部屋で貼り付けます。
5. 部屋のダイスボットは「インセイン」に設定してください。

コピーできない場合は「生JSON」を開き、全選択して手動コピーしてください。

## 入力と出力

- PCとエネミーの入力を独立して保持します。
- PCの66特技の目標値を自動計算します。習得が0個の場合は目標値が `?` になります。
- 特技はクリックで「未習得 → 習得 → 恐怖心 → 未習得」と切り替わります。
- Shift＋クリックで恐怖心だけを切り替え、習得と併用できます。
- 分野名で好奇心を指定／解除できます。5本のギャップは個別調整可能です。
- 横方向の折り返しと恐怖心の−2補正はチェックボックスで指定します。
- アビリティはチャットパレットに出力します。プリセットは名前のみで、効果文は自由入力です。
- 持ち物は個数0や自由入力分もステータスに出力します。入力した「控え」は駒に出力しません。
- アビリティと持ち物は駒メモへ自動追記しません。回避コマンドと特技の星印も出力しません。
- エネミーには正気度を出力しません。

## 保存と通信

入力は利用者のブラウザーのlocalStorageに保存されます。サーバーへのキャラクター情報の保存や、端末間同期はありません。ブラウザーのデータ消去で入力も消えることがあります。

倉庫読み込み時には `character-sheets.appspot.com` に通信します。ブラウザーや通信設定によって読み込みができない場合は、手入力で使用してください。

ローカル版とWeb版は保存場所が異なるため、ローカル版の入力がWeb版へ自動移行することはありません。

人物の秘密・使命などは駒メモに含まれます。貼り付ける前にプレビューで確認してください。

## 動作・構成

- 素のHTML・CSS・JavaScriptによる単一ファイル。ビルドや外部ライブラリは不要です。
- 起動時に4例の計算セルフテストを実行します。失敗バナーが出た場合は出力を使用しないでください。
- GitHub Pagesは `main` ブランチのルートを公開元に設定します。`.nojekyll` によりJekyll処理を無効にします。
- `noindex,nofollow` を指定しています。検索除外の指定であり、閲覧制限ではありません。
